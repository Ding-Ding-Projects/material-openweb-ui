Open WebUI, rebuilt in Material 3

Every model you run, wrapped in Material 3.

A frameless Windows desktop app for Open WebUI. Your chats, your models, your files and your one-time codes stay on the machine you are sitting at — no server to start, no account to make, and nothing in it is ever for sale.

Nine destinations, one tab strip

Every surface is a tab you open, pin, group, rename and close — not a page you scroll to find. The command palette reaches all of them, and lands on the exact control rather than somewhere near it.

Ctrl+Shift+F
Chat
Streamed replies from a model running on this machine. Markdown, code blocks, message actions, and a chat list that searches by plain text or by pattern.
Workspace
Models, prompts, knowledge and tools, each a real list with bulk actions, exports and its own search.
Admin panel
Users, roles and instance settings when the backend is running. When it is not, the panel says so instead of showing an empty table.
Ollama manager
The daemon, the installed models, the full published catalog with every tag, and pulls with real progress. Fit verdicts come from your actual RAM and VRAM, never from a model name.
File converter
Type detected from the actual bytes, not the extension. Eight adapter categories, and anything unavailable stays visible with the exact dependency it is missing.
Authenticator
Real RFC 6238 codes for whatever accounts you like, computed locally and checked against the published test vectors. No account, no sync, no network.
Settings
Language, funny level, narrator, schedules, school mode, appearance and logo. Every row explains itself and says whether the value is yours or a shipped default.
Status Hub
A live session card and a real event log. Every feature writes to it, so the log is what happened rather than what was expected to.
Changelog
Every released version in the app, filterable by date and searchable by pattern, and every entry links to the commit that made the change.

What is actually different

It runs where you are sitting
Chats, settings, one-time codes and converted files stay in this application on this computer. There is no account to make, and nothing you have to switch off to keep it that way.
English and Cantonese, side by side
Three language modes, and a funny-level slider for each language from fully serious to maximum playfulness. The voice changes; the facts never do.
Tabs you can lock, for fun
Any tab or element takes its own password or one-time-code lock, with its own credential. It is a speed bump you set for yourself, and the app says exactly that rather than claiming it protects anything.
Nothing on screen is decoration
If it looks like a control, it works. A button that cannot do its job names the condition that is unmet, and an empty state stays honestly empty instead of being filled with sample data.
Built on Open WebUI
This is a fork of the Open WebUI project, which does the hard work underneath. It keeps its name and its licence here; this project changes the interface, not the credit. Upstream: github.com/open-webui/open-webui
